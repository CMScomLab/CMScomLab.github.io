# Projects

CMScomLabで進行中、または過去に実施したプロジェクトの一覧です。

## Active Projects

### [net-vis](net-vis.md)
JupyterLab向けのインタラクティブなネットワーク可視化ライブラリ。NetworkXのグラフ構造を簡単に可視化し、スタンドアロンHTMLとしてエクスポート可能です。

### [Image Vector PoC](image-vector-poc.md)
画像のベクトル化技術を用いて、自然言語（日本語など）による画像検索の可能性を検証するプロジェクト。現在はGoogle SigLIPを用いたプロトタイプを開発中。

### [SAENM](saenm.md)
実験ノートを時系列に沿って追加し、判断の流れごと残す研究運用モデル。数か月にわたる実験を整理しながら、研究を継続的に前へ進める方法を実践しています。

### [ベクトル検索 ANN](vector-search-ann.md)
LSH Cascade PoCを引き継ぎ、IVF系の探索、Voronoi分割、量子化、ベクトルの幾何学的な特徴を大規模なデータで検証する研究プロジェクト。

### [VC/VP Employee Badge](vc-vp-employee-badge.md)
VC/VPの考え方を参考に、本人承認、項目単位の情報開示、短命な提示、失効、監査を独自方式で実現する社員証プロジェクト。

## Past Projects

### [LSH Cascade PoC](lsh-cascade-poc.md)
ITQ-LSHとセグメントフィルタリングを組み合わせた、高速ベクトル検索エンジンの実装実験。現在はベクトル検索 ANNプロジェクトへ研究を引き継いでいます。

### [Graph RAG PoC](graph-rag-poc.md)
ナレッジグラフとベクトル検索を融合させた次世代検索エンジンのPoC。情報の「構造」と「時間変化」を捉え、単なる類似検索を超えた深い洞察の導出を目指します。
